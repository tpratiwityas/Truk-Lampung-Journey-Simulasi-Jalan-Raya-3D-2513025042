## Deskripsi

3D Lampung Truck Race – Pecel Lele Gerobak Edition merupakan permainan balap sederhana berbasis web yang dikembangkan menggunakan JavaScript dan library Three.js. Pemain mengendalikan sebuah truk untuk menyusuri jalan raya hingga mencapai garis akhir berupa Menara Siger Lampung.

Sepanjang perjalanan pemain dapat mengumpulkan koin untuk memperoleh skor dan harus menghindari rintangan berupa batu yang dapat mengurangi jumlah nyawa. Permainan juga dilengkapi berbagai objek lingkungan seperti gedung, pohon, minimarket, warung pecel lele, awan, pesawat terbang, lampu jalan, serta sistem pergantian siang dan malam.

## Fitur Utama

* Lingkungan 3D berbasis Three.js
* Kendaraan truk yang dapat dikendalikan pemain
* Sistem skor dan nyawa
* Koin yang dapat dikumpulkan
* Rintangan berupa batu
* Sistem collision detection
* Animasi awan dan pesawat
* Sistem siang dan malam
* Efek suara klakson, kemenangan, dan kekalahan
* Tampilan HUD (Head-Up Display)
* Tombol restart permainan
* Finish line berbentuk Menara Siger Lampung

## Teknologi yang Digunakan

* HTML5
* CSS3
* JavaScript
* Three.js
* WebGL
* Web Audio API

## Cara Menjalankan Program

1. Download atau clone repository ini.
2. Buka file `index.html` menggunakan browser modern seperti Google Chrome atau Microsoft Edge.
3. Tunggu hingga seluruh objek berhasil dimuat.
4. Mainkan permainan menggunakan keyboard.

## Kontrol Permainan

| Tombol          | Fungsi      |
| --------------- | ----------- |
| W / Arrow Up    | Maju        |
| S / Arrow Down  | Mundur      |
| A / Arrow Left  | Belok Kiri  |
| D / Arrow Right | Belok Kanan |

### Interaksi Tambahan

* Klik matahari untuk mengubah mode siang dan malam.
* Klik truk untuk membunyikan klakson.
* Klik tombol Restart untuk mengulang permainan.
